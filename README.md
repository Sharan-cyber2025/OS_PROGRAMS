# Operating Systems Lab Programs

A complete collection of **Operating Systems Laboratory programs** implemented as part of the OS Lab curriculum. This repository contains practical implementations of UNIX commands, system calls, shell scripting, process management, CPU scheduling, synchronization, memory management, paging, file organization, and file allocation techniques.

* Filters and Pipes

* **D. Stat System Call**
